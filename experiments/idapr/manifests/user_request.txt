A1 无标签子空间估计函数（B 阶段也用同一个函数，单独放在 tools/analysis/idapr_basis.py 里，供两处 import）：

  def label_free_bases(Z, image_id, views, k_id, k_nuis, eps_ratio=0.1):
      # Z: [N,D] clean 嵌入（已 L2 归一化）；views: 同一批 RoI 的其他视图嵌入列表（各自 L2 归一化）
      # 1) 类间散度：同一 image_id 内不同框一定是不同目标
      Xb = []
      for im in unique(image_id):
          idx = where(image_id == im)
          if len(idx) >= 2: Xb.append(Z[idx] - Z[idx].mean(0))
      Xb = concat(Xb); S_b = Xb.T @ Xb / len(Xb)
      # 2) 类内散度：同一个框不同视图之差（不做中心化：系统性偏移本身就是扰动方向）
      R = concat([V - Z for V in views]); S_w = R.T @ R / len(R)
      # 3) 广义特征值问题 S_b v = λ (S_w + εI) v
      eps = eps_ratio * trace(S_w) / D
      L = cholesky(S_w + eps*I)                  # 下三角
      M = solve(L, solve(L, S_b).T).T            # = L^{-1} S_b L^{-T}
      w, U = eigh(M); U = U[:, argsort(w)[::-1][:k_id]]
      V = solve(L.T, U)                          # = L^{-T} U
      E_id = qr(V)[0]                            # [D,k_id]，正交列（QR 不改变张成空间）
      E_n  = top_eig(S_w, k_nuis)                # 无标签扰动子空间 [D,k_nuis]
      return E_id, E_n, dict(n_between=len(Xb), n_within=len(R), eps=eps, top_eigs=w_sorted[:k_id])

  只用 car、fit 视频（split_mask(video, 0)，与 S3 相同）。
  估计四次：F_stage1（views=[fap]）、F_stage3（views=[fap]）、HF_stage1（views=[fap]）、HF_stage3（views=[fap]）；
  另外用 F_stage4、HF_stage4（views=[fap,photo,student]）各估计一次，用来比较"视图种类多少"的影响。
  k_id ∈ {2,8,16}，k_nuis ∈ {2,8,16}。

  报告 A1 表（每个估计一行）：
    与身份 oracle、天气 oracle、FAP 残差 PCA（与 S3 相同、用 F_stage1 fit 视频估计）的主角（列出全部角度的中位数和最大值）；
    在 test 视频上的能量占比（与 P1 同口径）：真实跨域偏移、身份差异（identity_rows）、FAP 残差；
    stage1 与 stage3 估计的同维子空间之间的主角（稳定性）。

A2 遗忘还原测试（与 ics_probe_drift.py 的 restoration 部分完全同口径）：
  query_stage = 4，gallery_stage j = 1,2,3，test 视频，gap = 4，window = 30，max_q = 4000，seed = 0；
  对 E ∈ {无标签身份 E_id（F_stage1 估计）、无标签身份 E_id（stage3 估计）、无标签扰动 E_n（F_stage1 估计）、
         身份 oracle、FAP 残差 PCA、随机（10 次平均）}，k ∈ {2,8,16}，模型 ∈ {F, HF}：
    fixed = new − ((new − old) @ E) @ E.T，mAP_restored = cross_map(fixed, old, tasks)；
    恢复比例 = (mAP_restored − mAP_cross) / (mAP_same − mAP_cross)，先对三个 j 分别算，再对 j 平均。
  注意：HF 的无标签基用 HF 自己的特征估计；F 的用 F 的。

  自检（必须通过）：用身份 oracle 重新跑 A2，结果必须与 drift_restoration.csv 中已有数值逐项一致（差 < 1e-9）。

【阶段 A 过关标准】

      且 ≥ 身份 oracle（同 k）恢复比例的 70%；
  (2) 无标签扰动子空间 k = 2 的平均恢复比例 ≤ 10%。
  不满足就停止，提交 A 的结果，写明哪一条没过。

1) darth/models/utils/roi_proto_memory.py
   给 roi_proto_loss_with_gate 增加三个参数（默认值保持原行为）：
       space_mode='full', space_basis=None, space_gamma=1.0
   在函数开头（feats、prototypes 归一化之后），在原有 if/else 之前插入：

     if space_mode != 'full':
         assert basis is None or float(beta) == 0.0, 'space_mode 与 ICS 耦合不能同时开启'
         E = space_basis.detach().to(device=feats.device, dtype=feats.dtype)   # [D,k]，正交列
         sim = feats @ prototypes.t()                                        # 近邻仍在全空间用余弦选
         k = min(topk, sim.size(1))
         topv, topi = sim.topk(k=k, dim=1)
         d = feats.unsqueeze(1) - prototypes[topi]                           # [N,k,D]
         full2 = d.square().sum(-1)                                          # ‖d‖²
         in2 = (d @ E).square().sum(-1)                                      # ‖Eᵀd‖²
         if space_mode == 'id_only':       dist = 0.5 * in2
         elif space_mode == 'id_boost':    dist = 0.5 * (full2 + float(space_gamma) * in2)
         elif space_mode == 'release':     dist = 0.5 * (full2 - in2)
         else: raise ValueError(space_mode)
         per_roi = 1.0 - dist.mean(dim=1)
         cos_roi = topv.mean(dim=1)                       # 门控仍按原余弦相似度
         gate_mask = (torch.ones_like(cos_roi, dtype=torch.bool) if sim_gate_thr is None
                      else cos_roi.detach() >= float(sim_gate_thr))
         if gate_mask.sum() == 0: return None, cos_roi, gate_mask
         loss = (1.0 - per_roi[gate_mask]).mean()
         return loss, cos_roi, gate_mask

   说明：单位向量下 0.5‖z − p‖² = 1 − cos，所以 'full' 与这三种模式的尺度一致。
   在 compute_loss 的参数中增加 space_mode / space_basis / space_gamma，原样传给 roi_proto_loss_with_gate；
   last_stats 增加 space_mode 和 mean_in_share（= in2.sum()/full2.sum()，诊断用，需在函数里一起返回或记录）。

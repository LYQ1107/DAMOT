# Resolved configuration snapshots

The Python files are checkpoint/config snapshots used by the frozen evaluator
and profiler. They are included to document thresholds, module switches,
teacher settings, and stage identities. They are not standalone training
recipes: private data paths and checkpoint paths are redacted, weights are
omitted, and no new training is authorized by this bundle.

The effective V100 profiling settings are summarized in
`efficiency_effective_runtime.json`.

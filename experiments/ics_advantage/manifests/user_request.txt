【任务】ICS 优势的定量与可视化评估（只推理，不训练；两批模型，同一套流程）

================================================================
〇、背景（先读这一部分）
================================================================
项目：DAMOT，多目标跟踪（MOT）的无源持续域适应。源模型在 BDD100K Clear 上训练，然后按
Overcast → Rainy → Dawn/Dusk → Night 的顺序，在无标签目标域上依次适应（每个阶段称为 stage1–4）。
框架是 teacher–student 的 QDTrack（Faster R-CNN R50-FPN），有三个模块：
  - FAP：频域外观扰动（低频幅值 mask / 高频噪声），用来生成"外观变了、目标没变"的视图；
  - ICS：在关联嵌入（256 维）中找 2 个方向，在训练时对这 2 个方向做软收缩
         z' = z − α·(z·E)Eᵀ，再用 z' 多算一项关联损失（权重 loss_weight）；
  - APR：保存历史阶段的 RoI 原型，把当前嵌入往历史原型对齐，防止遗忘。
代码：GitHub 仓库 LYQ1107/DAMOT（main），服务器上的副本 /data1/liuyeqiang/DAMOT。
  ICS 代码：darth/models/track_heads/causal_quasi_dense_track_head.py（_add_trimmed_pcl）、
           darth/models/utils/roi_causal_bank.py（trim、bank 更新）。
  探针与分析脚本：tools/analysis/ics_probe_extract.py（抽特征）、ics_probe_analyze.py（split_mask、
           build_retrieval、retrieval_map 等函数）、ics_probe_drift.py。

为什么要做这个任务：
  之前的分析发现，原来 ICS 选的方向接近"身份方向"，在多数实验里测不出作用。后来换成"干预方向"：
  对同一个框，比较"加了扰动的视图"和"干净视图"的嵌入差，取变化最大的 2 个方向。
  在一个短实验里（C 系列，见下），用干预方向做 ICS（C2）在 Night 上的 AssA 比不用 ICS（C0）高 0.69、
  比随机方向（C4）高 0.53，但只有一个种子、HOTA 只高 0.25，还不足以下结论。
  本任务要用更扎实的统计（按视频配对、置信区间）和更有针对性的指标（对干预的不变性），
  判断这个优势是否真实，并画出论文可用的图。目标是测准，不是放大：结果不支持时也要如实报告。

名词与模型（第一批）——"C 系列"短实验：
  运行目录：/data1/liuyeqiang/ics_v2_20261030_184026（各组 checkpoint 路径和 sha256 见
           manifests/final_model_provenance.json；配置差异见 runs/<组名>/config_diff.json；
           说明见该目录的 SUMMARY.md。该目录尚未推送到 GitHub）。
  共同设置：都从同一个 HF stage3 checkpoint 出发（模型已适应完 Overcast、Rainy、Dawn/Dusk），
           只在 Night 上继续训练 2 个 epoch；关闭 APR；4 张 V100；种子 1790355234；
           causal_min_samples=32；roi_proto_couple_ics=False。
  各组只有 ICS 不同：
    C0：不用 ICS（对照组）
    C1：老版 ICS（global_pc_ema，1 个方向，α=0.25，权重 0.1，bank 从头估计）              ← 补充
    C2：干预方向 ICS，方向固定，α=0.25，权重 0.1                                        ← 主要考察对象
    C3：同 C2，但 α=0.5（收缩更强）                                                    ← 补充
    C4：随机正交 2 个方向，方向固定，α=0.25，权重 0.1（排除"随便收缩都有用"）              ← 对照组
  "主比较"= C2 对比 C0（有没有 ICS）和 C2 对比 C4（方向选得对不对）；C1、C3 只作补充参考。
  已有结果（Night HOTA / AssA）：C0 33.41/39.42，C1 33.39/39.45，C2 33.67/40.11，C3 33.39/39.65，C4 33.41/39.57。

      （proto_shrinkage_cov_ema，α=0.1，权重 0.025）。结果见其 results/stage_domain_metrics.csv。

一、按视频配对的跟踪指标
目的：一个总的 HOTA 噪声很大；同一段视频上两个模型逐一相减，能更准地判断差距是否稳定。
================================================================
1. 对每个评估域（第一批：Night、Dawn/Dusk；第二批：四个目标域），计算每段视频的 HOTA、AssA、IDF1、IDSW。
   优先使用已有的冻结评估预测（C 系列在 ics_v2 运行目录下，HF 在其运行目录下），用 TrackEval 逐视频输出，
   all-frame 口径与原评估一致；找不到预测文件的才补跑推理（协议与原评估完全相同）。
   先核对：逐视频结果汇总后，必须与已有的总指标一致。
2. 配对差值：第一批为 C2−C0、C2−C4；第二批为 新运行−HF。对每段视频求差，报告：
   - 平均差、中位数差、提升的视频比例；
   - 按视频重采样的 bootstrap 95% 置信区间（10000 次，seed0）；
   - Wilcoxon 符号秩检验 p 值（双侧）。
3. 难度分层（事先固定，不得更改）：
   目的：如果 ICS 的作用是"让表示对环境变化不敏感"，那么环境越极端（越暗），它的帮助应该越大。
   - 每段视频的亮度 = 所有帧灰度均值的平均（用原图计算）；
   - Night 域内按亮度三等分（最暗 / 中 / 最亮），各层分别报告配对差值与置信区间；
   - 第二批另外把四个目标域的全部视频合并后按亮度三等分，再做一次；
   - 报告"差值 vs 亮度"的 Spearman 相关系数（预期为负：越暗提升越大）。
   图：横轴为视频亮度，纵轴为 AssA 配对差值，每段视频一个点，加上分层均值与置信区间。

================================================================
二、干预不变性（特征层面）
目的：直接测 ICS 想达到的效果——同一辆车加雾、变暗、加 FAP 后，特征是否仍接近原图，
     而且这种变化远小于"换一辆车"造成的变化。
================================================================
数据：Night 与 Dawn/Dusk 的全部 test 视频，car，GT 框；
     用 ics_probe_extract.py 抽 clean、fap、photo 视图，以及剂量视图
     dark ∈ {0.80, 0.60, 0.40, 0.25}、fog ∈ {0.15, 0.30, 0.45, 0.60}、fapk ∈ {0.90, 0.70, 0.50, 0.30}
     （每段视频取前 5 个抽样帧做剂量视图；dark 数值越小越暗，fog 越大越浓，fapk 越小 FAP 越强）；
     所有模型使用完全相同的帧与框（抽完后核对 video/instance_id/frame_id/bbox 逐项一致）。
指标（每个模型、每个视图/强度分别报告）：
  (a) 干预不变性比 IR = mean‖ẑ(干预) − ẑ(clean)‖ / mean 最近异身份距离
      （ẑ 为 L2 归一化嵌入；最近异身份距离：同一帧内该 RoI 的 clean 特征到其他车 clean 特征的最小距离；
       越小表示干预造成的变化相对"换一辆车"越小）；
  (b) 跨干预身份检索 mAP：查询为 clean，图库为该干预视图（P2 口径），并报告 clean→clean 作参照；
  (c) 身份轮廓系数：把 clean 与全部干预视图混合，以 instance_id 为标签，用余弦距离计算 silhouette score
      （越高表示同一辆车的各版本聚得越紧、不同车分得越开）。
统计：(a)(b) 按视频 bootstrap 95% 置信区间，并给出与对照模型（第一批 C0、C4；第二批 HF）的配对差值区间。
图：
  剂量曲线——横轴为干预强度，纵轴为 IR（dark、fog、fapk 各一个子图），每个模型一条线并带置信带；
  柱状图——各模型的平均 IR、跨干预 mAP、轮廓系数。

目的：把第二部分的结论画得直观。注意 t-SNE 只用于展示，结论以第一、二部分的定量结果为准。

   - 同一轨迹同一颜色，四个版本用不同形状，干预版本用细线连到 clean 点；

S3 跨阶段漂移分解（CPU，用 S1 和已有的 F stage1–4 clean 特征，不需要 GPU）
================================================================
目的：检验"天气方向的漂移不伤害旧域关联，身份方向的漂移才导致遗忘"。
对 F、HF（NOGEOM 完成后也做）：
  记 z_k(r) 为第 k 阶段 checkpoint 对同一 RoI r 的归一化嵌入（各阶段 RoI 完全相同，已校验）。
S3.1 漂移分解：对每个相邻阶段 (k-1→k) 和 (1→4)，Δ(r) = z_k(r) − z_{k-1}(r)。在以下子空间（都用 fit 视频估计，
     F_stage1 的特征上，m = 2 和 16 两档）上报告 ‖PΔ‖²/‖Δ‖² 的均值：
     FAP 残差 PCA、天气 oracle、身份 oracle、当前 ICS（该阶段 bank）、随机。分别对"旧域 RoI"和"当前域 RoI"统计。
S3.2 跨阶段检索（模拟 APR 用旧原型匹配）：对每个旧域 j < k，query 用 z_k、gallery 用 z_j
     （同一视频、帧间隔 gap/window 与 P2 相同），算 ID mAP_cross(k←j)；同时算 mAP_same(j←j)。
     遗忘代理 = mAP_same − mAP_cross。
S3.3 归因：把 Δ 中某个子空间的分量还原回去（z_k' = z_k − P_W (z_k − z_j)，W 分别取 FAP 残差 PCA 和身份 oracle，
     m = 2/8/16），重新算 mAP_cross。
     预期支持论点的结果：还原身份 oracle 分量能明显减少遗忘代理，还原 FAP/天气分量基本不变。
S3.4 F 与 HF 对比：耦合 APR（HF）在补空间的漂移是否比 F 小，在 ICS 子空间的漂移是否更大。
交付：experiments/ics_probe/drift_decomposition/ 下的 CSV、LaTeX 表，以及一张图
     （横轴子空间、纵轴漂移能量占比；第二子图为各子空间还原后的遗忘代理）。

S4 推理时子空间干预的跟踪评估（只推理，1 张 GPU，约 2–3 h）
================================================================
目的：用真实 HOTA/AssA 代替 P3 的离线检索，检验去掉哪类方向对关联有害或有利。
实现：在 track_head 推理时得到关联嵌入后、送入 tracker 之前，加一个可配置的线性变换
     z ← z − β·(z Eᵀ)E，变换后按原来的方式进入 tracker，默认关闭（只加开关，不改其他逻辑）。
     E 从 npz 读取或由 S2 的结果导出，保存为 .npy。
基：
  (a) 当前 ICS（bank_pcs, m=2）
  (b) FAP 残差 PCA（m=2，只用 clear_holdout_45v 的 RoI 估计，无需目标域标签，避免泄露）
  (c) 身份 oracle 前 16 维（fit 视频估计，作为负对照，预期 AssA 明显下降）
  (d) 随机 2 维
β ∈ {0.5, 1.0}；β=0 即原始结果（必须与已有冻结评估数值一致，先做这一致性检查）。
checkpoint：F_stage4_e5 与 HF stage4 epoch5；评估域：4 个目标域全部。
交付：每个 (checkpoint, 基, β, 域) 的 HOTA/DetA/IDF1/AssA，以及相对 β=0 的差值表。

      只训练 Night 阶段，epochs-per-stage = 2（四组相同，以便公平比较；不要与 5 epoch 的完整结果直接比较绝对值）。
APR 历史原型：先确认 HF 是否保存了 stage1–3 的 <stage>_roi_proto.pth。若没有，用 rebuttal 脚本 profile_damot.py rebuild
      的方式，由 stage1–3 checkpoint 在各自域上重建历史原型；四组使用同一份原型（记录 sha256）。
四组（只改 track_head 下列字段，其余与 HF 完全相同，包括几何与高低频设置）：
  S5-a  causal_pca_mode='proto_shrinkage_cov_ema', roi_proto_couple_ics=True   （= HF 原设置，短训练对照）
  S5-b  causal_pca_mode='proto_shrinkage_cov_ema', roi_proto_couple_ics=False
  S5-c  causal_pca_mode='pairwise_residual',       roi_proto_couple_ics=True
  S5-d  causal_pca_mode='pairwise_residual',       roi_proto_couple_ics=False
  pairwise 两组：causal_residual_normalize_before_delta=True，min_samples 保持 96；bank 从 checkpoint 继承，
  不手动重置；记录训练开始和结束时的 num_updates，并统计 insufficient_pairs 的次数。
  若有空闲的 NOGEOM stage3 checkpoint，可在其上重复四组（第二优先级）。
评估：Night 与三个旧域（Overcast、Rainy、Dawn-Dusk），HOTA/DetA/IDF1/AssA；
     遗忘 = 旧域在 stage3 checkpoint 上的值 − 本次训练后的值。

分析：
  耦合效应    = (a−b) 与 (c−d)
  估计器效应 = (c−a) 与 (d−b)
  重点看：c 的旧域遗忘是否最小；c 的子空间是否最接近天气 oracle。
